# Стиль текста (правила владельца)

Пишем так, как написал бы мастер химчистки, который объясняет клиенту из Калининграда.

- Начинать сразу с сути, без подводки.
- Сообщать факт, а не его важность. Вместо оценки — деталь.
- Простые слова, прямые конструкции, действующее лицо названо.
- Примеров и пунктов столько, сколько требует смысл.
- Позицию высказывать прямо; оговорки только при реальной неопределённости.
- Один тон. Заканчивать последней содержательной мыслью, без итога и морали.
- Список — только если читатель будет сверяться по пунктам.

Не использовать:
- пустые противопоставления «не просто X, а Y», «дело не в X, а в Y»;
- спор с воображаемым возражением, театральные заходы («давайте разберёмся»);
- рубленые фразы для драматизма и многозначительные концовки;
- «играет ключевую роль», «важно отметить», «уникальный», «комплексный подход»;
- шлейфы «обеспечивая», «подчёркивая», «что делает его»;
- рекламный восторг, ссылки на безымянных экспертов;
- канцелярит: «является», «осуществлять», «данный», «в рамках»;
- тире как универсальную связку (только где требует грамматика).

Перед публикацией перечитать: что звучит как шаблон, что сообщает о важности вместо факта,
что можно удалить. Не выдумывать факты.
